# AGENTS.md — Windows app

> **Scope guard:** this file governs only `windows/` (Rust). The macOS app is a separate Swift codebase in [`../macos/`](../macos/) ([`../macos/AGENTS.md`](../macos/AGENTS.md)) — **never** create or edit files there unless the user explicitly asked for a macOS change. Routing rules, push procedure, and the wrong-codebase STOP check: [root `../AGENTS.md`](../AGENTS.md). Shared behavior contract: [`../common/spec.md`](../common/spec.md).

Rust system-tray app. Crates: `native-windows-gui 1.0.13` (UI), `windows 0.58` + `windows-core 0.58` (WASAPI/Win32). Single self-contained exe (static CRT via `+crt-static` in `.cargo/config.toml`), no admin, unsigned.

## Layout

| Path | Purpose |
| --- | --- |
| `src/main.rs` | Mode dispatch (`--version/--list/--daemon/--crash-test/--ui-smoke`, default GUI), single-instance mutex, DPI awareness |
| `src/audio/engine.rs` | 250 ms enforcement thread, `SharedState` (target/locked/rearm/status), 3-strike backoff |
| `src/audio/discovery.rs` | WASAPI endpoint enumeration, Jabra 85h match, default-capture fallback |
| `src/audio/notify.rs` | `IMMNotificationClient` → device-change rescan |
| `src/tray.rs` | nwg UI: tray icon + control window, glow animation, layout |
| `src/glow_icon.rs` | Pure-std glowing-dot ICO frame renderer |
| `src/autostart.rs` | HKCU `Run` registry toggle |
| `src/crash.rs` | Panic hook → MessageBox + log path; `fatal_error` |
| `src/logger.rs` | 1 MB rotating log → `%LOCALAPPDATA%\JabraInputTracker\app.log` |
| `assets/` | ICO/BIN icon blobs (committed; generated by `tools/`) |
| `tools/make_windows_icons.py` | Tray ICOs (pure stdlib Python) |
| `tools/make_app_icon.rs` | Window/taskbar icon container (pure-std Rust, `include_bytes!`'d) |

## Build / verify (CI enforces all of these)

```bash
export PATH="$HOME/.cargo/bin:$PATH"          # rustup installed with --no-modify-path
cargo fmt
cargo check --target x86_64-pc-windows-msvc
cargo clippy --release --target x86_64-pc-windows-msvc -- -D warnings
```

- Crate sources for API reference: `~/.cargo/registry/src/index.crates.io-*/`.
- `Cargo.lock` is committed — keep it updated.

## Release flow

1. Bump `version` in `Cargo.toml`, commit, push `main` (push procedure in root `AGENTS.md`).
2. `git tag vX.Y.Z` and push the tag → `.github/workflows/windows.yml` builds and attaches `JabraInputTracker-vX.Y.Z-windows-x64.zip` to a GitHub Release titled **`Windows vX.Y.Z`** (title set by the workflow — keep the platform prefix).
3. CI also runs `--list` and `--ui-smoke` on windows-latest — a startup panic fails the build. Keep both modes working.

## Conventions & gotchas

- **nwg event binding**: never `full_bind_event_handler` on a `TrayNotification` handle — it is `ControlHandle::SystemTray`, `.hwnd()` is None → panic at startup (v1.1.2 fix). Tray events arrive in the parent window's handler.
- **Single-instance**: `CreateMutexW` returns Ok even when the mutex exists — check `GetLastError() == ERROR_ALREADY_EXISTS (183)`.
- Enums from windows-rs are transmuted to i32 for comparisons — keep the explicit `unsafe { transmute }` pattern used in `tray.rs` and add a comment.
- Behavior contract shared with macOS: see `../common/spec.md` (includes the agreed defaults — 100% target, lock ON, launch-at-login ON — and the current parity status per platform).
